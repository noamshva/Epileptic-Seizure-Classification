# results/

Evaluation outputs written by `src/4.run_eval_chbmit.py`:

- `eval_summary.csv` — per-class precision / recall / F1 and overall accuracy.
- `confusion_matrix.png` — seizure vs non-seizure confusion matrix.
- `roc_curve.png`, `precision_recall_curve.png` — when both classes are present in the eval set.

All generated content is gitignored; only this README is tracked.
